# c--

Невелика інтерпретована мова програмування, написана на C#.

## Запуск

```
dotnet run
```

Після запуску введи шлях до файлу з кодом мови.

## Синтаксис

### Змінні

Змінна створюється ключовим словом `let`. Текст беремо в одинарні лапки.

```
let text = 'Hello'
let number = 2500
```

### Коментарі

Рядок, що починається з `//`, ігнорується.

```
// це коментар
```

### Вивід: Console.print

Виводить текст або значення змінної.

```
Console.print('Привіт')   // виведе текст
Console.print(text)       // виведе значення змінної text
```

### Ввід: Console.input

Виводить підказку й чекає, поки користувач введе рядок.

```
Console.input('Введи ім'я: ')
```

### Пауза: `Console.pause`

Зупиняє програму на вказану кількість мілісекунд.

```
Console.pause(2500)
```

## Приклад програми

```
let text = 'Hello'
Console.print(text)

Console.input('Натисни Enter: ')
Console.pause(2500)
Console.print('Готово')
```

## Обмеження

- Усі значення змінних зберігаються як рядки.
- Одна команда на один рядок.

## Планування
- В нових оновлення ми додамо щоб коли ви створювали зміну let <назва_зміной> = Console.input('Який твії вік: ') то щоб поверталось тещо ввели
- Та ще плануємо додати списки, індекси, типи даних, словники
